一、基本概念

1.1什么是漏洞？
漏洞（Vulnerability）指的是系统、软件或网络中存在的弱点，可能被攻击者利用来破坏系统安全。漏洞通常来自以下几类原因：
（1）软件错误：程序代码写错、输入校验不足、逻辑漏洞等。
（2）配置不当：端口暴露、权限设置过高、默认密码未修改。
（3）协议缺陷：如明文传输、缺少加密或验证机制。
（4）人为疏忽：弱密码、操作失误、安全意识不足。
正如著名计算机科学家 Edsger W. Dijkstra 说过：“编程就是不断制造错误的过程。”
软件越复杂，漏洞自然越多，因此漏洞扫描和安全检测显得尤为重要。
1.2 常见漏洞扫描工具概述
漏洞扫描工具可以帮助我们发现系统中的弱点，以下是常用的几类工具：
① OpenVAS
开源的综合漏洞扫描系统，适合对服务器和网络进行全方位检测。
② Nmap（含 NSE 脚本）
除了端口扫描外，Nmap 的脚本引擎可以检测弱口令、服务漏洞、配置问题等，是安全测试人员必备工具。
③ Netcat（nc）
被称为“网络界的瑞士军刀”，可用于端口连接、数据传输、测试后门等场景。
④ OWASP ZAP
适用于 Web 安全测试，可发现 SQL 注入、XSS、认证缺陷等常见 Web 漏洞。
二、理论基础
2.1 漏洞扫描概念
漏洞扫描是通过自动化工具对目标系统进行安全检测，识别已知安全弱点的过程。它与渗透测试的关系：
被动扫描：仅识别漏洞，不进行利用
主动扫描：可能包含验证性测试，但不超过破坏性界限
2.2 扫描类型分类
按目标分类：
├── 网络扫描（端口/服务发现）
├── Web应用扫描
├── 数据库扫描
├── 操作系统扫描
└── 无线网络扫描
按认证方式：
├── 非认证扫描（外部视角）
└── 认证扫描（内部视角，需凭据）
